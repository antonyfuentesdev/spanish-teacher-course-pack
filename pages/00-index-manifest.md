## How to use this page (people)

- Bots never read this page: they read <code>manifest.json</code> on GitHub (version, release tag, and for every file its tag-pinned raw link and SHA-256) and check each downloaded file against its SHA-256. The version line above matches the manifest's version.
- A downloaded file counts as complete only if its SHA-256 matches the manifest (one retry). "Ends with" below is a reading aid for people checking a file. If a file is missing or fails its check, the bot does not improvise its content: it tells the learner that part of the course is temporarily unavailable and continues with what is available (13.11 Gates §10).
- A saved copy may be reused while the manifest shows the same version and tag. When either changes, the bot downloads the changed files from the new tag and checks them again.
- The learner's own progress is never stored here; it lives in the progress file on the bot's computer, <code>/workspace/spanish-teacher/progress.md</code> (13.11).
