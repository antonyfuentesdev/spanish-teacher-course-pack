The standard 30-minute voice session, how sessions combine into sittings of up to 2 hours, what each session of a topic contains and the materials every topic needs. Flow from Aula Internacional / Nuevo Prisma; voice habits from Language Transfer (pause, think, answer) and Pimsleur (graduated recall). Correction and voice protocols are in 13.8; review limits in 13.10.

## Sessions inside a topic

A topic runs 10–16 sessions (13.1). Sessions differ in purpose so the same template doesn't repeat ten times:

| Sessions | Purpose | What changes |
| --- | --- | --- |
| 1–3 | Introduce | Main focus in session 1; one supporting item or chunk set per session after that |
| 4–6 | Practise and vary | New scenarios; tasks adapted to the learner's goal (travel, work, family) |
| 7–8 | Extend | Different formats: story building, guessing game, short debate, retelling |
| 9 (or 9–13 in longer topics) | Recycle | Mix this topic with earlier ones; revisit logged errors |
| Last | Topic check | 10 min warm-up review, about 8 min check (13.9 topic-check template, fixed Form A; retakes B, C; after a failed fast-track: check B, retakes C, D), then feedback and free chat; no new content |

Each course adds <b>2 consolidation sessions</b> before its last topic check (one extended role play that needs the course's main points together; see 13.1). A learner may fast-track a topic only at its session 1, once, with Form A: 8/10 or more and Part B 4/4 skips the remaining sessions (at most 3 fast-tracks a week; 13.11 Gates §3). The fast-track is <b>offered at the start of session 1, before any teaching</b> (not to a self-declared beginner during course A1.1, unless they ask), and is optional; below 8/10 the session simply continues as a normal lesson. The regular topic check is never on the same day as the topic's last new-content session.

<b>Graded writing task (typed track):</b> done in the typed block after the topic's last recycle session before the check (session 9 at A1–A2; the session before the check at higher levels), about 15 minutes in chat. It is recorded as an Assessments row, type Writing task, and the weekly summary shows "writing tasks x of n" against the level's minimum (13.9 §3).

## Sequence and timings (30 minutes)

| Step | Minutes | What happens |
| --- | --- | --- |
| 0. Opening | 1 | Greeting, today's goal, the final speaking task announced |
| 1. Input | 4 (B2–C1: 6) | Short dialogue or story played twice; 2–3 gist questions |
| 2. Noticing | 3 | Bot points to one form from the input; learner spots the pattern; rule in 1–2 sentences |
| 3. Practice | 7 | 6–8 items, controlled first, then personal; at most 2 correction rungs per item, then the model (13.8) |
| 4. Speaking task | 8 | Real-life task; errors handled as in 13.8 (recast only during the task, feedback after) |
| 5. Pronunciation | 3 | One sound: same or different, repeat, use in a phrase; scored 0–2 (13.9) |
| 6. Spaced review | 3 | Up to 8 due items, out loud (13.10) |
| 7. Close | 1 | 3-line spoken summary; full summary posted in chat (13.11) |

- <b>Mini-lesson:</b> when an error has been logged 3 times (13.10), the next session swaps 2 minutes of practice for a 2-minute mini-lesson on it
- <b>Learner talk time:</b> target at least 12 of 30 minutes (practice, task, review); input and rules are bot talk by design
- <b>Optional typed block:</b> if the learner has the typed track on, add 5 minutes in chat after the call (Learning plan overview, typed track); the learner can switch the typed track on or off any time. It uses only the topic page: the §10 short text once the sessions have taught everything in it (before that, today's script as text), today's exercise items answered in writing, and a line of today's script or model dialogue as dictation
- <b>Materials per session:</b> §3 scripts and §5 exercise items are matched to the session outline by focus (a topic page may list them under §2 as "Materials per session"); nothing is written live
- <b>Short first lesson (10 min, intake only):</b> opening, input, 4–5 practice items, close; a Lesson row that counts toward the daily cap and lesson hours but does not advance the session number
- <b>Typed lesson:</b> when voice is not used, the same session runs in chat with the same materials (no pronunciation step); it counts as a lesson session
- <b>Short session (15 minutes):</b> for busy days: 2-minute opening, 10 minutes of due review, 3-minute mini-practice of today's topic. It is a Review row (learning hours), not a lesson
- <b>A1:</b> input 5, noticing 3, practice 7, task 7 (more support, shorter task). <b>C1:</b> input 6, practice 5, task 10

## Sittings (60–120 minutes)

A study day of up to 2 hours is a <b>sitting</b> of blocks, not one long session:

| Block | Minutes | What happens |
| --- | --- | --- |
| 1 | 30 | Lesson session (the sequence above) |
| Break | 5 | Learner stands up; the bot ends the call or waits |
| 2 | 30 | Next lesson session, in a different format (13.2 session purposes) |
| Break | 5 | — |
| 3 | 30–40 | Review (the study day's share, 13.10), typed track, then free conversation or bot-narrated listening |

- <b>At most 2 new-content lesson sessions per calendar day</b>; everything else that day is recycling, review or free talk (13.11 Gates §1). A 10-session topic therefore takes at least 4–5 study days
- Change mode between blocks (dialogue, story, game, typed) to limit fatigue from one synthetic voice; the bot offers to stop when answers slow down or errors rise in block 3
- A 60-minute sitting = blocks 1 and 3; a daily 30-minute learner does block 1 and its in-lesson review only
- Each block is its own Sessions row (Type Lesson, Review, Typed or Free talk)

## Input rules

- Neutral Latin American Spanish for Mexico, Costa Rica, Colombia and Panama in every scene; a regional word appears only when labelled with its countries (13.8 regional-awareness table)
- The bot announces each speaker before their line ("Habla el mesero:"), or uses a second voice if that turns out to be possible
- Length: A1–A2 30–60 s; B1 1–2 min; B2–C1 2–4 min with 2–3 speakers, natural speed, hesitations and interruptions written into the script
- <b>Honest limit:</b> all input is voiced by the bot's own synthetic voice. From B2 the bot also recommends outside listening (radio, podcasts, series) and can discuss it, because a single voice cannot train "varied accents" (13.9 listening 5)

## Bot script pattern

Instructions follow the English-use policy in 13.8: at A1 every instruction is in English (or the learner's own language), with only the Spanish being taught in Spanish; at A2 rules in English, instructions in simple Spanish; from B1 Spanish. Exact learner-facing lines for status, checks and exams: 13.11 Learner-facing words.

<b>0. Opening</b> (first line always states where the learner is, or asks: 13.11)

- B1+: "¡Hola, \[nombre\]! Vamos por \[tema\], sesión \[n\]. Hoy vamos a \[function\]. Al final vas a \[final task\]."
- A1: "Hi \[name\]! Today is session \[n\] of \[topic\]. Today you'll learn to \[function\]. At the end you'll \[final task\], in Spanish."
- Session 1 of the course only: A1–A2: "If you need time to think, say «a ver…» or «un momento», and I'll wait." B1+: "Si necesitas pensar, di «a ver…» o «un momento», y te espero."
- A1–A2: "If you didn't understand me, say «otra vez» or just "again", and I'll say it slower."

<b>1. Input</b>

- "Escucha. Habla \[speaker\]: …" → "Otra vez." → gist questions modelled first at A1 ("Ana: ¿Le gusta el café? Sí, le gusta. Ahora tú: …"). A1 frame: "Listen to Ana. … Again. Now: does Ana like coffee? Answer in Spanish: «Sí, le gusta»."
- If no answer: replay the key line slowly, then offer two choices

<b>2. Noticing</b>

- "¿Qué dijo Ana exactamente? … ¿Notas algo en el verbo?"
- Rule in one or two sentences plus two examples; in English at A1–A2 (13.8)

<b>3. Practice</b>

- "¿Cómo dirías…?" (A1: "How do you say…?" or "Say: …") → wait (turn-holding rules in 13.8) → confirm, or correction rung 1 → rung 2 → model
- Gap items are never read with a spoken blank; they are turned into prompt-first items (13.8 Spoken items)
- When the target hangs on an unstressed ending or stress, use the ending check before correcting (13.8)

<b>4. Speaking task</b>

- "Ahora un juego de roles. Tú eres \[role\], yo soy \[role\]. Empiezas tú." (A1: "Now a role play. You're the customer, I'm the waiter. You start.")
- During the task: recast only, and only when meaning is blocked; all other errors noted for after
- After: "Muy bien. Dos cosas para mejorar: …"

<b>5. Pronunciation</b>

- "Escucha: \[minimal pair\]. ¿Iguales o diferentes?" → "Repite: …" → "Ahora en una frase: …" (A1: "Listen: pero, perro. Same or different?" → "Repeat: …")
- The 0–2 drill score is recorded only; the learner hears and sees "Pronunciation practice: done"

<b>6. Spaced review</b>

- "Repaso rápido. ¿Cómo se dice…?" (A1: "Quick review. How do you say…?") → answer out loud → "¡Exacto!" or the model; result written to the Review queue in the progress file (13.10)

<b>7. Close</b>

- Three spoken lines: what you did well, one thing to fix, next session

## Rules

- One <b>main</b> grammar focus per topic, plus the supporting items listed in 13.1; one sound per topic
- At most 5 new active review items per lesson session at A1–A2, 6 at B1+, never more than 10 on one day (13.10); other words go on the passive list
- <b>Personal facts come from the Profile</b>: when a topic teaches the learner to talk about themselves, the bot teaches their real facts as chunks even if the grammar or numbers come later (a 34-year-old learns «Tengo treinta y cuatro años» as one chunk in A1.1-1, even though the topic's numbers stop at 20). The Profile holds age, city and job for this
- At A1–A2, supporting items beyond the main focus are introduced as chunks and practised mainly in the recycling sessions and review blocks, so the 10 core sessions are not overloaded (13.1)
- Before each session the bot re-reads the progress file (or uses the next session brief if the file can't be read in a call; 13.11 assumption A1); after every call it writes the file from the call transcript using the write procedure in 13.11 (a Sessions row with the drill score; an Assessments row for any check; Review queue updates; Milestones if a gate is met), then the memory summary ("Where progress lives" in the Learning plan overview)

## Materials checklist (per topic)

Nothing below may be improvised live. Only topics published in this course pack can be taught or checked (locked levels, 13.11 Gates §10). <b>The list of all 48 topics is 13.12 Topic materials.</b>

- [ ] Topic sheet: main focus, supporting items, chunk list, active and passive vocabulary, sound, variety notes; at A1–A2, which recycling session practises each supporting item
- [ ] Session outline for every session (10–16), following the table above
- [ ] 3–5 input scripts at level, with gist questions and answers
- [ ] Exercise bank: at least 30 items with expected answers and the common errors to expect
- [ ] 2 task cards: roles, situation, success criteria
- [ ] Listening items at A1–A2: at most 3 short options, read twice, or a short spoken answer
- [ ] Pronunciation drill: Spanish-only minimal pairs or perception items (don't rely on the bot producing an English sound), phrases, what counts as 2/1/0
- [ ] <b>Topic check Forms A, B, C and D</b> (13.9 §2; Form D is used only after a failed fast-track, as the second retake, so no form is reused for the same learner): each with 5 spoken items + 1 listening item (at least 3 spoken items unseen, each marked seen/unseen), a Part B role play different from the session tasks, answer key with accepted variants
- [ ] <b>Anchors:</b> for Part B, one sample answer scoring 4/4 and one scoring 2/4, with why
- [ ] Review seed list (5–6 active items per session), with 3 items marked as fast-track retention seeds
- [ ] Typed track: 1 short text with 3–5 questions and 1 graded writing task with a model answer (counts toward the typed minimum, 13.9 §3)
- [ ] One variety throughout
